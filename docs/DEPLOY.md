# Запуск: домен, хостинг і посилання для підтримки

Домену й посилань поки немає — це нормально. Нижче найкоротший шлях, щоб запустити безкоштовно вже сьогодні й
додати власний домен пізніше. Підтримка (кава) працює вже з однією банкою Monobank.

## 1. Хостинг безкоштовно, з безкоштовною адресою (Cloudflare Pages)
Чому саме він: безкоштовний, віддає статичні файли (наш `www/`), **читає `public/_headers`** (CSP та інші заголовки безпеки),
сам повертає `index.html` для маршрутів застосунку, а статичні SEO-сторінки `/en/ideas/…` віддає як є. Адреса буде
`https://<назва-проєкту>.pages.dev`.

1. Покладіть проєкт на GitHub (репозиторій може бути приватним).
2. На <https://dash.cloudflare.com> → **Workers & Pages → Create → Pages → Connect to Git**, оберіть репозиторій.
3. Налаштування збірки:
   - **Build command:** `npm run build`
   - **Build output directory:** `www`
   - **Environment variables:** `NODE_VERSION` = `22`
4. Після першого деплою у вас є адреса на кшталт `https://advent-tram.pages.dev`. Додайте змінну
   **`SITE_URL` = `https://advent-tram.pages.dev`** (без слеша в кінці) і зробіть Retry deployment.
   Саме тоді з'являться canonical, hreflang, sitemap та картинки для соцмереж.
5. Перевірте: `https://…/robots.txt`, `https://…/sitemap.xml`, `https://…/en/`, `https://…/uk/ideas/…`.

Інші варіанти: **Netlify** (так само читає `_headers`; додайте файл `public/_redirects` з рядком `/* /index.html 200`),
**Firebase Hosting**. GitHub Pages **не рекомендую**: він не вміє заголовків безпеки.

## 2. Власний домен (коли захочете)
- Домен купується окремо, орієнтовно 10–20 € на рік (`.com`, `.app`, `.eu`; для України ще `.com.ua`). Реєстратори:
  Cloudflare Registrar (за собівартістю), Namecheap, Porkbun, Hostpro (для `.ua`). Назва: коротка, без дефісів, наприклад `adventtram.app`.
- У Cloudflare Pages → проєкт → **Custom domains → Set up a domain** і слідуйте підказкам (DNS додається за кілька кліків).
- Змініть `SITE_URL` на новий домен і повторіть деплой. Стару `.pages.dev` адресу краще лишити з редіректом на новий домен.

## 3. Посилання для кнопки «Buy me a coffee»
Усе налаштовується в одному місці: `src/environments/coffee.ts`.

```ts
export const SUPPORT_LINKS = {
  monobankJarUrl: 'https://send.monobank.ua/jar/XXXXXXXX',   // українська мова (і запасний варіант для всіх)
  paypalMeUrl: '',                                          // інші мови, коли з'явиться
};
```

**Банка Monobank (достатньо одного цього):**
1. У застосунку Monobank → **Банка** → створіть банку (назва, мета, можна без суми).
2. Відкрийте банку → **Поділитися / Посилання** → скопіюйте адресу виду `https://send.monobank.ua/jar/…`.
3. Вставте її в `monobankJarUrl`. Якщо `paypalMeUrl` порожній, банка використовується **для всіх мов** (її можна поповнити картками Visa / Mastercard
   і з-за кордону; суму вибирає платник — тому варіанти €1/€3/€5 лише підказка).

**Міжнародний варіант (необов'язково):**
- `paypalMeUrl` — адреса виду `https://paypal.me/ваше-ім'я`; сума підставляється автоматично (`…/3EUR`).
  ⚠️ Чи доступне **отримання** платежів на рахунок PayPal для вашої країни та типу акаунта, я перевірити не можу — подивіться на сайті PayPal.
- Інші сервіси (Ko-fi, Revolut, Wise тощо) мають свої умови для різних країн; перед вибором перевірте, чи можна на них отримувати гроші з вашої країни.
  Якщо оберете інший сервіс, скажіть мені: підключу його так само, як PayPal.

Поки жодного посилання нема, кнопка підтримки сіра й неактивна — це безпечний стан.

## 4. Пошук (після запуску з `SITE_URL`)
1. **Google Search Console** → Add property → **URL prefix** → ваша адреса → підтвердіть (HTML-тег або DNS) → **Sitemaps** → `sitemap.xml`.
2. **Bing Webmaster Tools** → імпорт із Google Search Console одним кліком.
3. Через 1–3 тижні в Search Console з'явиться «Indexed pages».
4. Додайте посилання на `https://ваш-домен/en/` (і мовні версії) у соцмережах, профілях, описах у магазинах застосунків.

## 5. Чек-лист перед публічним запуском
- [ ] `SITE_URL` задано, у `view-source` видно `<link rel="canonical">` і hreflang
- [ ] Є хоча б одне посилання підтримки (кнопка на `/coffee` активна)
- [ ] Заголовки безпеки видно (DevTools → Network → відповідь `/` → `Content-Security-Policy`)
- [ ] Сторінки `/privacy` перевірено (за потреби додайте контактну пошту)
- [ ] Переклади вичитано носіями (див. `docs/TRANSLATION_REVIEW.md`)
